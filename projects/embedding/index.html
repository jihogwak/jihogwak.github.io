01 / 프로젝트 소개

같은 텍스트, 서로 다른 표현 경로

임베딩 모델의 차이를 숫자만으로 이해하기는 어렵습니다. 두 모델을 선택하고 입력 처리부터 encoder, 표현 추출, 출력과 검색까지의 경로를 나란히 따라가는 화면을 만들었습니다.

02 / 배경과 목적

사양표를 넘어 모델 안의 차이를 보기

처음에는 차원 수와 입력 길이, 모델 크기를 비교하는 화면으로 시작했습니다. 이후 어떤 단계에서 표현 방식이 달라지는지 직접 살펴볼 수 있도록 구조 비교를 중심으로 바꿨습니다.

03 / 구현한 것

하나의 입력으로 두 모델을 비교하기

BGE, E5, GTE, Jina, EmbeddingGemma, OpenAI 계열의 대표 모델을 선택할 수 있습니다. Query와 Document를 전환하고 단계별 블록을 선택하면, 해당 단계의 역할과 두 모델 사이의 차이를 확인할 수 있습니다.

04 / 문제 해결 과정

그림에서도 구조를 정확하게 구분하기

BGE의 dense·sparse·multi-vector 출력 경로는 분리하고, Jina의 task LoRA는 encoder 내부에 표시했습니다. 내부 구조가 공개되지 않은 모델은 추정해 그리지 않고, 공개된 입력·출력 범위에서 비교하도록 구성했습니다.

05 / 결과물

직접 조작하며 이해하는 구조 시각화

모델 선택, A/B 교환, 입력 역할 전환, 단계 이동과 블록별 설명을 연결했습니다. 사양표와 공식 출처는 보조 자료로 남겨, 구조를 살펴본 뒤 수치와 근거도 확인할 수 있게 했습니다.

06 / 배운 점

비교의 기준이 화면의 구조를 바꿉니다.

더 많은 정보를 나열하는 것보다, 같은 입력이 각 모델에서 어떻게 처리되는지를 같은 기준으로 보여주는 것이 중요했습니다. 도식의 벡터와 점수는 설명용 예시이며 실제 모델 추론 결과와 구분했습니다.

07 / 이어서 보기

두 모델을 골라 경로를 따라가 보세요

구조 비교 화면에서 모델과 입력 역할을 바꾸고, 각 단계의 블록을 눌러 차이를 살펴볼 수 있습니다. 이 페이지의 비교 자료는 원래 시각화에 기록된 출처 확인 시점을 기준으로 합니다.

01 / 프로젝트 소개

같은 정보를 서로 다른 기준으로 보는 문제

연구분야, 특허, 산업의 분류체계는 서로 다른 목적으로 구축됩니다. 이를 연결하면 각각의 데이터에서 따로 보던 정보를 함께 분석할 수 있습니다.

02 / 배경과 목적

각각의 분류 결과를 잇는 방식의 한계

분류체계마다 독립된 분류기를 학습한 뒤 결과를 결합하면 분류 오차가 매핑으로 전달될 수 있습니다. 학습에서 관측하지 못한 분류 조합을 표현하는 문제도 남습니다.

03 / 진행한 일

생성형 AI와 임베딩 기반 연계 연구 참여

2025년 주요 분류체계 매칭 연구와 2026년 연구분야·특허·산업 분류체계 연계 모델 시범 구축 과제에 참여했습니다. 연계 모델 개발과 데이터 기반 매핑 성능 검증을 다뤘습니다.

04 / 접근 방법

매핑 자체를 검색하는 의미 단위로 보기

관련 연구 원고에서는 두 분류 코드의 임베딩을 합성해 하나의 매핑 표현을 만듭니다. 문서를 같은 의미 공간에 정렬하고, 한 축을 공유하는 양방향 구조적 네거티브로 두 분류 축을 구분하도록 학습합니다.

05 / 결과물

과제 수행과 관련 연구 기록

두 연구과제의 참여 기록과 교차 분류체계 매핑 관련 연구 원고를 정리했습니다. 관련 원고 「합성 임베딩을 통한 교차 분류체계 매핑」에서 접근 방법과 검증 내용을 확인할 수 있습니다.

06 / 배운 점

무엇을 연결하는지부터 다시 정의하기

이 연구에서 중요하게 본 관점은, 기존 분류 결과를 어떻게 이을지만 고민하지 않고 연결 대상인 매핑을 직접 표현하는 방식으로 문제를 다시 보는 것이었습니다.

07 / 다음 방향

연결된 정보를 실제 탐색과 분석에 활용하기

분류체계 연계를 통해 이용자가 서로 다른 데이터 사이에서 관련 정보를 찾고 새로운 연결을 발견하도록 돕고 싶습니다.
